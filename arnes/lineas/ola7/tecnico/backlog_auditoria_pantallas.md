## Cómo se usa este documento

1. Cada hallazgo nuevo de Javier se agrega como una fila a la tabla de la sección correspondiente (§1 Diseño / §2 Código / §3 Decisiones).
2. Un hallazgo puede *abrir* un diamante (documento de planificación propio, linkeado desde acá) si su alcance lo amerita — no todo hallazgo necesita uno.
3. **Estado de una fila:** `auditado` (reportado, sin plan aún) → `planificado` (tiene diamante/plan con Goal-Input-Output) → `aprobado` (Javier dio luz verde a ejecutar) → `ejecutado`.
4. Nadie escribe código desde este documento sin pasar por `aprobado` explícito.
